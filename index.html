Introduction

Pourquoi apprendre le DOM ?

Le DOM (Document Object Model) est la représentation de la page HTML que le navigateur donne à JavaScript. Grâce à lui, ton code peut lire la page, la modifier, réagir aux clics et aux saisies, et afficher des données. C'est le pont entre la logique JavaScript que tu connais déjà et ce que voit l'utilisateur.

Mode d'emploi

Comment marche le bac à sable ?

Chaque étape contient une page HTML de travail (l'escalier, une liste, un formulaire, un catalogue…) et des challenges.

  1. Lis la notion, puis l'onglet HTML du bac à sable pour connaître la page.
  2. Clique sur Coder ici sous un challenge et écris ton JavaScript dans l'éditeur.
  3. Exécuter (ou Ctrl + Entrée) lance ton code sur une page neuve. La console affiche tes console.log et tes erreurs.
  4. Vérifier teste ton code automatiquement. Ton code et ta progression restent enregistrés dans ce navigateur.
  5. Le bouton 💾 Mon travail exporte ton travail dans un fichier (pour le garder, changer d'ordinateur ou l'envoyer à ton formateur) et copie un résumé de ta progression.

Pour lancer la plateforme sur ton ordinateur, ouvre un terminal dans le dossier du projet :

npx serve .
